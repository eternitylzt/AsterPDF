# AsterPDF 使用说明

## 阅读

使用指针选择文字和图片，使用手形拖动页面。左右键翻页，上下键滚动；单页视图到达边缘后滚轮翻页。按 F5 进入演示，按 Esc 退出。左侧提供页面、目录、书签、搜索、批注和图片列表。

## 对象编辑与字体

进入对象编辑后直接选择对象，双击文字输入；拖动移动，拖动右下角缩放，Delete 删除。Ctrl+Enter 应用，Esc 取消。没有修改内容时退出不会重写文字，原 PDF 字形保持不变；删除和移动不需要字体。

输入默认匹配系统字体。原字体缺失时会显示替代字体名称。点击“查找字体”可按名称搜索开放字体，也可导入本地字体。下载需联网，缓存到应用数据目录的 fonts 子目录，以后离线复用。来源与许可证随字体保存，仅注册到本程序，不安装到系统。相近字体不保证与原字体版式一致；同名字体也可能版本不同。商业字体和特殊字形不保证可获得，缺少输入字形或限制嵌入时会提示并保留草稿。

## 批注

高亮、下划线和删除线支持拖选部分文字。便笺内容显示在批注列表中。颜色按钮选择颜色，“线宽”和“不透明度”分别控制粗细和透明程度。“样式”中可设置批注人、文本字体字号和箭头端点；实心箭头使用标准填充箭头。

## 提取与导出

进入提取模块自动启用区域工具，再拖动框选；单击其它位置取消选框。“导出设置”保存 DPI、像素宽度、格式和 JPG 质量，也用于高清复制。原始图片提取会打开图片列表，列表与页面互相定位；重叠图层可从列表选择，Ctrl / Shift 多选。提取原始图像通道，软蒙版不会自动合成，不以页面截图代替原图。没有图片时列表显示提示。

## 合并与保存

首页可新建合并队列，也可加入全部已打开 PDF（包括当前未保存编辑），再添加、排序或移除文件。结果另存为新 PDF。页级内容会复制，但文档级目录、脚本及表单树不会导入；检测到相关内容时会在合并前提示。

保存 Ctrl+S，另存 Ctrl+Shift+S，撤销 Ctrl+Z，重做 Ctrl+Shift+Z。修改后文件名有星号。恢复副本不会覆盖原文件。

## 兼容边界

支持已识别的 LaTeX animate 控件/图标帧动画和适用的内嵌 MP4、音频；播放受编码和平台限制。不执行 PDF JavaScript。当前不支持 OCG 动画、Flash、3D 和外部媒体。嵌套矢量组支持整体变换，支持直线路径端点拖动，不支持贝塞尔控制柄或复杂全文重排。页面裁剪只改变可见框，框外内容仍可能恢复。

Windows 为实际测试平台；macOS 和 Linux 提供构建配置，尚未在实际环境验证。完整功能范围、许可证和测试记录见软件随附的 docs 目录。


## 0.4 界面与文字属性

右键工具栏可自定义功能、隐藏、自动隐藏与透明度。左边缘箭头收起导航，右键可设置自动隐藏。标签末尾下拉菜单列出全部文档。语言切换保留当前文件状态；Ctrl+F 打开侧栏搜索。

编辑 → 文字打开左侧属性面板，双击文字块后可选中字符，分别调整字体、字号、粗体、斜体和颜色。失败草稿可撤销、取消或切换工具；返回文字面板继续。若其间修改了 PDF，请复制草稿并重新选取对象，避免将旧位置应用到新内容。

页面组织网格支持多页拖动、删除和在页间插入 PDF。“换色”修改当前页实际纯色内容，图片可选参与；渐变、图案、专色、批注与动画帧不参与。

动画菜单可选自动、原像素或流畅画质；自动播放宽度最多 1280 像素，暂停按钮恢复原像素。普通阅读始终按显示器实际 DPI 绘制。播放按时间推进，复杂帧可能跳过。

文件菜单提供信息和 Ctrl+P 打印。打印为 300 DPI 按页渲染（3200 万像素上限），实物打印机尚未验证；保留矢量请使用 PDF 提取/导出。


## 0.7 新增操作

- Ctrl + 滚轮围绕鼠标位置缩放；工具栏右侧的方向按钮显示溢出工具，图标只在同组内拖动排序。
- 编辑中的图片、图形、换色按钮打开并排设置栏。PDF 图可保留矢量插入；EPS/PS 需本机已安装 Ghostscript。
- 在页面上选择对象后复制、粘贴，会保留原大小和位置；粘贴结果按组合对象移动或缩放。文字编辑器中的内部复制粘贴也保留字符样式。
- 批注“选择”从空白处拖框多选，按 Delete 删除。便笺可移动，有内容的批注可悬停预览。
- 编辑菜单提供还原文档、恢复副本目录设置与手动恢复入口。每次已应用修改会保留恢复版本；文字草稿在输入暂停 350 ms 后自动记录。
- 关闭多个修改过的文档时，依次激活各标签询问保存。恢复不会自动覆盖原文件。
- 页面水平/垂直翻转适用于没有链接、批注和媒体的内容页；含交互内容的页面仍可旋转。

常见合字需要整体选择后修改。复杂编码、嵌套 Form 标签和全文排版仍有限制；不可用的逐字操作会提示原因，取消后原文不变。

## 速览窗

右上角悬浮缩略导航：点击跳至页内位置，拖动蓝色可见区域框浏览正文。滚轮或按住右键拖动预览，右键设置位置/比例，拖边缘调整大小。关闭后由“视图 → 速览窗”重新打开。20 页以内默认 10%，超过 20 页默认 5%；范围 0.5%–20%，宽页适应窗宽。

## 0.8 页面操作与速览窗

页面组织拖动缩略图到蓝色插入线的位置即可重排。裁剪/旋转等操作在侧栏选择范围并应用或取消。裁剪框支持八个调节点；默认删除框外内容，跨边界文字/矢量对象会整项删除；可勾选保留模式。含表单/动画/媒体的页面仅支持保留模式。速览窗跟随单双页，自动比例为20页内10%、超过20页5%，右键可自定义。旧的整篇文档滚动条选项已移除。


## 0.9 设置与文本框

Ctrl+, 打开分类首选项；界面字号可选小/中/大，首页最近文件可隐藏。设置同步到打开文档，文本草稿保留。

页面组织选中某页后，“当前页”指该预览页。旋转/翻转按钮直接生效，取消撤回当前栏本轮操作，离开则保留。

插入文本框起始为光标宽度，输入后扩展；拖边框可设置换行宽度，拖上方圆点旋转，文字栏可输入精确宽度/角度。Ctrl+Enter 应用，Esc 取消。

速览窗默认不透明度 80%，自动定尺寸，最高为半屏；悬停 Ctrl+滚轮每格约 1%。书签星随当前页点亮，列表右键可重命名。


## 1.0 换色与搜索

换色面板自动读取所选范围，源色按估计可见面积排序，最多 64 色。可使用取色、容差、多对替换与保存方案。图片换色需勾选栅格图片；渐变矢量、图案、批注、动画帧不参加换色。区域边界仅用于提示，不写入 PDF。

搜索可找到已应用的新文字；F3 / Shift+F3 或上一条/下一条逐条定位。速览窗用半透明亮色带标记结果，底部显示阅读进度。设置入口固定为 Settings → 语言/Language。

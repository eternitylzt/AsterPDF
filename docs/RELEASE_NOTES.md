# AsterPDF 1.3.9

## 中文

- 长文档优先显示阅读页，滚动时按可见范围绘制。
- 优化逐字删除、文字预览以及图形和图片的移动、缩放。常见局部操作只更新相关页面内容，支持撤销、恢复与另存。

## English

- Long documents prioritize the reading page and draw only visible rows while scrolling.
- Character deletion, text previews and object transforms reuse existing PDF data. Common local edits update the affected page stream and retain undo, recovery and Save As.

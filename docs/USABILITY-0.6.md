# AsterPDF 0.6 操作说明 / Usage notes

## 文字编辑

双击文字块进入编辑，拖动选择字符后设置颜色、字号、加粗或倾斜。支持 Ctrl+C、Ctrl+V 和面板内的复制/粘贴按钮。Ctrl+Enter 或“应用”写入 PDF；Esc 放弃草稿，“取消”同时关闭文字属性区。没有改动时离开，不写入任何内容。

本版将样式变化与输入新字符分开处理。颜色、加粗和倾斜继续使用原字形与字体资源，不再因此换成本机字体。加粗采用轻微描边，倾斜采用几何变换；不是把字体替换成别的粗体/斜体。原字体本身就是粗体时，取消其固有字重需要明确选择一个常规字体。

输入、粘贴、删除和样式变化会生成**局部 PDF 草稿预览**，光标与选区使用同一预览的字形坐标。预览稍作合并延迟，不保存整份 PDF，也不刷新整个页面。应用后仍保存真正的文字内容，不把文字变成图片。

新增字符优先复用可用的内嵌字体；缺少字形时，只为新增字符选取本机字体，并在面板显示提示。原有字符不因此改字体。复杂编码、裁剪文字、无法可靠对应的连字等仍可能拒绝逐字编辑；草稿可以复制、撤销或取消，整个对象仍可移动/删除。复杂全文重排与任意科研公式编辑不属于支持范围。

## 工具栏与阅读

- 在主工具栏上直接按住图标，拖到另一图标的位置后松开。顺序保存在设置中，并同步到其它打开的文档。
- 右键工具栏的“自定义”只用于勾选显示项目。页码、缩放框保留固定位置；图标可以互相调整顺序。
- 透明工具栏的下沿作为初始阅读区域顶部；页面滚动后才会经过透明工具栏下方。单页/双页非滚动视图水平、垂直居中。
- 缩放范围为 **1.5625%–6400%**。100% 按当前显示器报告的物理尺寸计算，切换显示器后重新换算。显示器或远程桌面报告错误物理尺寸时，100% 也可能不准确；本版没有尺子校准功能。

## 换色与导出

“编辑 → 换色”增加本页、全部页面、指定页码范围。存在选区时增加“选定区域”，并默认采用该范围。一次批量修改对应一次撤销。

区域换色保留文字和矢量，使用框内/框外的互补裁剪组合。不识别裁剪范围的文字提取器可能读到跨边界文字的两份内容；换色后的页面内容也会成为组合对象。对这类场景建议使用整页换色，或保留原文件副本。对话框会在执行前显示这一限制。渐变、图案、批注与动画帧不参与换色。

单页或区域导出使用“另存为”对话框，预设名称为 `原文件名_p0001_region.png` 等，可直接修改。多页图片批量导出仍选择文件夹，DPI、质量和默认格式沿用导出设置。

## 文本批注与列表

选中“批注 → 文本”后，在页面空白处双击输入，也可拖出区域后输入。文本框按内容向下扩展；接近页面底部放不下时会明确提示。选中已有文本批注后，可拖动八个边框控制点调整大小、重新排版，也可拖动内部移动。双击修改内容。其它形状的任意控制点编辑没有在本版增加。

左侧批注列表覆盖整个文档，包含页码、作者、内容与时间。可按创建时间（没有创建时间时使用修改时间）或文档中从上到下的位置排序；旧批注缺少时间时显示“时间未记录”。点击列表条目会定位对应页面。

“显示所有批注”仅控制页面阅读显示。取消勾选不会删除批注，列表仍保留；保存、导出和打印仍包含原有批注。

## Validation boundaries

Windows x64 is the tested platform; macOS/Linux configurations are supplied but unverified. The text preview uses the actual PDF patcher, not a Qt substitute-font approximation. Geometric bold/slant retain font identity but do not reproduce a typeface designer's dedicated bold/italic masters. New glyphs may still require an explicit substitute. See [validation](VALIDATION.md) for measured workflows and [compatibility](COMPATIBILITY.md) for the full limits.

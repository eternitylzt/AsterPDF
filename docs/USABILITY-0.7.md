# AsterPDF 0.7 使用变化 / Usage changes

## 阅读与工具栏

Ctrl + 滚轮围绕鼠标所在的 PDF 位置缩放。非连续单页/双页的右侧滚动条默认覆盖整个文档；“视图”可切换回页内滚动条。导航默认按标签需要的宽度显示，拖动细分隔线调整宽度，双击或拖到底收起，左侧箭头展开。

工具栏超出窗口宽度时显示左右箭头。直接拖动按钮，用半透明预览与插入标记排序；指针/手形、四个模块、其它工具分别在各自组内排序。页码与缩放控件保持固定。透明工具栏在初始阅读/页面组织时预留空间。

## 悬浮便捷浏览

默认右上角显示全文缩略导航，蓝色半透明框标出当前正文可见区域。点击缩略页定位到页内位置，拖动蓝框快速移动正文；滚轮或按住右键拖动只移动缩略预览。单页、双页、连续阅读均可用。

右键选择四个角的位置、缩略比例（0.5%–20%，默认 10%）、跟随阅读位置或关闭；拖动边缘调整宽高。“视图 → 便捷浏览”可重新打开，也可添加到自定义工具栏。宽页自动适应悬浮窗宽度；整条文档长度由右侧细轨和页数表示。缩略图按可见范围异步加载，缓存上限 8 MB，切换到其它文档或关闭时释放；预览为静态页面，动态内容仍在正文播放。

目录条目增大行距，标题过长可悬停查看全文。浅色/深色滚动条使用更鲜明的滑块与悬停色。

## 文字编辑

双击对象进入编辑；光标、拖选、复制不会触发原文修改。真实期刊的大文字对象使用缓存字形映射，新增尾部文字时保留旧内容流。格式操作仍尽量保留源字体，不要求先安装原字体。新输入若原字体无字形，会显示实际采用的本地替代字体。

常见合字（如 ffi）保留原 PDF 字形。只改合字中的一部分不能可靠保留原字形时，会明确提示选中整个合字；不会静默改字体或写入猜测结果。嵌套 Form 中的标签、裁剪文字与特殊编码仍有限制。没有实现全文排版。

文本编辑器之间复制粘贴保留字符样式及可用的嵌入字体。退出文本编辑器后选择 PDF 对象，Ctrl+C / Ctrl+V 会原位复制文字、图片或矢量组到当前/其它文档；这些粘贴结果作为矢量 Form 组移动、缩放，内部文字不递归拆开编辑。

## 图片、图形和换色

在“编辑”内选择对应按钮打开并排属性栏：

- 图片：选择栅格图或 PDF，PDF 可指定页码，点击或拖动放置。PDF 图保留矢量和文字。EPS/PS 仅在本机已安装 Ghostscript 时可转换，不额外打包该组件。
- 图形：矩形、椭圆、线、实心箭头、三角形、菱形、星形；设置填充、轮廓、线宽后绘制。可选中直接路径再应用样式，直线路径可拖端点。
- 换色：本页、全部、指定页或选区；已有选区默认选区，也可点击“框选换色区域”。区域外不换色。此操作使用原始/改色矢量裁剪组，跨边界文字可能被部分提取器重复提取；渐变、特殊颜色空间、批注及动画帧不改动。

网页链接由系统默认浏览器打开，仅处理 HTTP(S)/mailto 和已识别的文档内跳转，不执行文件启动动作或 PDF 脚本。

## 批注与页面

批注元信息采用较小字形/次要颜色，正文另起一行。便笺可拖动；文本框边框显示移动光标，八个调节点显示方向光标，改变宽度后重新换行并保证文字可容纳。所有有文字的批注支持悬停预览。

“选择”工具从空白处拖框可多选，正文或列表中按 Delete 批量删除。新增批注后清除旧选择。样式/内容编辑仍限 AsterPDF 添加的批注。

页面旋转保留所选页，可连续旋转；可拖动页面预览排序，删除直接执行且可撤销。内容页可水平/垂直镜像；含批注、链接或媒体的页面暂不镜像，执行前会说明。

## 保存、还原与恢复

“编辑 → 还原文档”载入最近保存的文件，正文还原可撤销；未应用文字草稿需确认后放弃。退出时依次激活未保存标签并询问保存/放弃/取消，保存后继续处理其它标签。

每次已应用修改都有磁盘恢复副本；文字草稿在输入暂停 350 ms 后记录。进程异常终止后，下次启动提供恢复；不会自动覆盖原文件。恢复文件夹可在“编辑 → 恢复副本设置”选择，旧目录仍会扫描。恢复后建议另存为。不是无限历史备份：磁盘版本仍有数量/容量上限。

## English summary

Mouse-anchored zoom, compact navigation, grouped toolbar dragging/overflow, docked color/image/vector tools, original-position object clipboard, journal text mapping/append improvements, annotation marquee/hover/movement, persistent rotation selection, content-page mirrors, sequential unsaved-tab closing and configurable crash recovery.

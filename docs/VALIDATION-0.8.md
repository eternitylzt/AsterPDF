# AsterPDF 0.8 验证记录 / Validation

2026-09-17 · Windows 11 x64 build 26200 · Python 3.12.10 · PySide6 6.10.2 · PyMuPDF 1.27.1 · pikepdf 10.3.0.

## 本轮结果

完整回归 **63 项通过，152.42 秒**。[测试汇总](evidence/tests-0.8.json)。此次新增/调整了页面组织拖放、裁剪、侧栏页面操作、双页速览测试；此前文字编辑、对象剪贴板、动画、批注、导出、恢复等回归继续通过。

- **拖放排序：** 将真实 Qt DragEnter/DragMove/Drop 事件发送到页面列表视口，验证接收、插入线、向前/向后移动、多选整体移动，保存重开后页内容顺序正确。旧测试只直接调用 dropEvent，未检查 Qt 是否接受拖放；已替换该测试。没有声称已做真人长时间拖放试用。
- **裁剪交互：** 侧栏默认不保留框外内容；框选和调整八个调节点时版本不变，取消不改文档，应用指定页范围才写入 PDF。旋转所有页面后仍可再次应用。旁栏在较矮窗口中可滚动。
- **删除式裁剪：** 对 0°/90°/180°/270° 页面保存重开，框内文字与矢量保留，框外测试文字从内容流中消失，已提取图片不含原框外红色像素，未改页内容流保持字节一致。撤销恢复原文件字节；保留模式扩大裁剪框后仍能看到原框外文字。
- **事务与限制：** 对包含动画 Widget 页的批量删除式裁剪明确拒绝，文档路径和版本保持不变，不留下已裁一半的结果。跨边界文字/路径会整项删除，这是明确的能力边界，不宣称通用矢量几何裁切。原文档、其它页、附件及本机撤销/恢复历史不作为隐私清理对象。
- **其它页面侧栏：** 全页逐页插入空白页、指定范围删除、提取两页为新 PDF、侧栏合并为五页新文档已保存重开验证；文件名选择保留系统对话框。
- **速览窗：** 用户论坛手册 30 页，在三台真实显示器（DPR 2.5/1/1）显示双页行，自动采用 5%；短文档 10%，单双页切换与右页定位通过。私有文档未改变。[记录](evidence/page-tools-0.8.json)。

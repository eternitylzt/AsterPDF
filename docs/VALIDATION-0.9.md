## 本版实际流程

1. **页面组织：** 选中第三页、旋转及再次旋转，预览尺寸和 PDF Rotate 同步；点击取消时即使操作尚在执行，也等待完成再整体撤回本栏操作。退出保留旋转。水平翻转后渲染不同，取消后像素恢复，文档恢复到未修改状态。
2. **文字栏：** 在图片、图形、文字工具间反复切换，文字属性容器始终有可用宽度。进入编辑默认展示文字栏。
3. **新文本框：** 中文输入、调宽换行、旋转、保存重开、重新进入不改动再退出，均通过。实际 Qt 鼠标事件拖动边框和旋转柄；检查小幅拖动没有突然跳转大角度。取消不污染缓存对象；移动后再次编辑不会跳回原插入点。
4. **用户 78 页教材：** 使用提供的《数据处理入门》实测 IME 提交中文，首次编辑框宽度约 8 个逻辑像素；方向为 (1,0)，旋转 45° 后保存重开方向约 (0.7071,0.7071)。原文件 SHA-256 未改变。原文和截图不分发。
5. **独立阅读引擎：** Poppler 渲染保存的公开样例，中文、按宽度换行与旋转文字可见，保留文字/矢量。[图示](evidence/poppler-text-box-0.9.png)。Poppler 对示例的其它 Symbol/ArialUnicode 显示字体给出缺失提示；所加文字使用嵌入字体。没有声称执行 Acrobat 测试。
6. **设置与导航：** 首选项保存后同步；设置过程中保留文字草稿、不提交 PDF。首页历史开关、速览窗透明度、每格 1% 缩放、半屏高度限制、对象方向键微移与书签星随页变化通过。书签重命名使用真实 Qt 菜单及输入框事件，名称写入本机阅读状态。
7. **屏幕与字号：** 三台显示器 DPR 2.5 / 1 / 1（包括笔记本 4K 屏），文字栏宽度均为 225 逻辑像素；速览窗符合高度上限。小、中、大字号、深浅主题、重复调整窗口宽度、工具栏溢出及标签角部对齐做了实际 Qt 窗口检查。[记录](evidence/usability-0.9.json)

## 已知边界与未验证项

- Windows x64 已运行打包程序；**macOS/Linux 仅有构建配置，本轮未构建运行**。未签名、未公证；未测试物理打印机。
- 新增文本框支持按字形宽度换行与旋转，不是完整文字排版引擎；复杂文字塑形、竖排、原始任意段落自动重排仍不支持。控件边框以未旋转的排版框为参照，文字角度独立预览；选择框不提供 Illustrator 式旋转坐标系统。
- 旋转/翻转不会静默处理不支持的媒体/批注镜像；取消范围是当前工具栏本次操作，切换操作栏或使用全局撤销后会结束该范围。
- 本轮没有重新进行长时间内存/动画性能基准；播放验证证明多帧解码及基本交互，不等于任意文档在所有设备达到原生帧率。既有 Science 文本、180 帧保持及崩溃恢复专项记录见 [0.7](VALIDATION-0.7.md)，裁剪专项见 [0.8](VALIDATION-0.8.md)。
- 没有创建 GitHub 仓库或发布 Release。ZIP 校验和、源码编译和 EXE 哈希核对在打包时执行；源包只包含两个公开示例 PDF。

See [usage](USABILITY-0.9.md) and [compatibility](COMPATIBILITY.md). Source tests and Windows diagnostics are provided; results are not extrapolated to untested platforms or arbitrary PDFs.
